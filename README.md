# Personal Portfolio Website | Deepak Kandasamy

Source code for my personal portfolio website, hosted on GitHub Pages. Built using [Jekyll](https://jekyllrb.com/) and the [Minima](https://github.com/jekyll/minima) theme.

**Live Site:** [deepak-kandasamy-aiml.github.io](https://deepak-kandasamy-aiml.github.io)

---

## 🚀 Overview

This site serves as a central hub to showcase my work as a **Principal Data Scientist**, bridging enterprise-scale AI solutions with personal research in **Reinforcement Learning (RL)** and **Generative AI (GenAI)**.

### Featured Sections
* **Home:** Core focus areas in Enterprise AI, RL, and GenAI.
* **About:** Professional background, leadership philosophy, and credentials.
* **Projects:** Deep dives into personal RL frameworks, GenAI implementations, and open-source contributions.
* **Writing/Posts:** Articles and insights on AI systems and applied machine learning.

---

## 🛠 Tech Stack

* **Static Site Generator:** Jekyll
* **Theme:** Minima
* **Hosting & CI/CD:** GitHub Pages + GitHub Actions
* **Language:** Markdown, Liquid, HTML/CSS
